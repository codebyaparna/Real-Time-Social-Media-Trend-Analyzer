# 📊 SocialPulse AI – Real-Time Social Media Trend Analyzer

An interactive **Data Science dashboard** built using **Python, Streamlit, Pandas, Plotly, Matplotlib, and NLP** to analyze social media sentiment and visualize trending insights.

## 🌐 Live Demo

🔗 https://socialpulse-ai.streamlit.app/

## 💻 GitHub Repository

🔗 https://github.com/codebyaparna/Real-Time-Social-Media-Trend-Analyzer

---

## 🚀 Features

- 📊 Interactive Analytics Dashboard
- 😊 Sentiment Analysis (Positive, Negative & Neutral)
- 📈 Dynamic Pie & Bar Charts
- ☁️ Word Cloud Visualization
- 🔍 Tweet Search Functionality
- 📋 Dataset Preview
- 📥 Download Processed Dataset
- 🎲 Random Tweet Generator
- 📊 Real-time Dashboard Experience

## ▶️ Installation

Clone the repository:

```bash
git clone https://github.com/codebyaparna/Real-Time-Social-Media-Trend-Analyzer.git
```

Move into the project directory:

```bash
cd Real-Time-Social-Media-Trend-Analyzer
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run utils/app.py
```
